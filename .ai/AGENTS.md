# Agent Roles

## Discovery Agent
- Defines users, pains, assumptions, risks, and validation questions.

## Prototype / UX Agent
- Defines portal/dashboard look and feel and user flows.

## Product Owner Agent
- Converts discovery into MVP scope, roadmap, and ticket drafts.

## Orchestrator Agent
- Creates technical tickets and Context Packs with explicit scraper/job risks.

## Coder Agent
- Implements exactly one ticket at a time with tests.

## Reviewer Agent
- Reviews correctness, simplicity, N+1 risks, idempotency, and documentation.

## Knowledge Curator Agent
- Updates concise decisions, summaries, and status after each ticket.
