# Governance

- Agents propose. The human decides.
- The Orchestrator controls context, not individual agents.
- Each agent has a bounded role.
- Each ticket should be small enough to implement and review independently.
- No agent should read the full repository by default.
- No agent should read full conversation history by default.
- Official docs and summaries replace old chat history.
- Any medium/high-risk technical decision must be escalated.
- Code must be reviewed before being considered complete.
- Documentation must be updated after meaningful changes.
- Scraping, jobs, deduplication, and notifications are first-class product areas.
