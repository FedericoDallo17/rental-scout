# Token Optimization

- Start from the current ticket and its Context Pack.
- Read only the docs and files named in Required Reading unless new evidence requires more.
- Summaries should link to source files instead of repeating them.
- Reuse templates instead of inventing custom formats.
- Prefer concise acceptance criteria and direct findings.
- Avoid loading unrelated tickets.
- Keep portal and scraper/job context separated unless the ticket needs both.
