# Provider Samples - 2026-07-12

Captured during a bounded live probe for Ticket 020. These are raw provider responses used to validate adapter parsing and future data-model decisions.

- `remax-listings.json`: RedREMAX list API for Pocitos rentals.
- `housi-search.html`: Housi server-rendered Tokko search results for Pocitos apartment rentals.
- `imperium-listing-properties.json`: Imperium Inmobiliaria list API for Pocitos rentals.

MercadoLibre is not included because public API and HTML probes returned access/login gates from this environment. Sorhuet is not included because the targeted Pocitos route returned no properties; the broad rental route was lower-confidence and deferred.
