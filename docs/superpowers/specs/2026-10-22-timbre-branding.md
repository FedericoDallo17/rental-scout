# Timbre identity integration

User approved implementation of the completed Timbre brand kit: round panelled door,
no fixed frame, outward motion, green/ivory icon, Patio palette, Manrope Variable,
and the es-UY “Con un guiño” voice.

Apply the selected identity to authenticated navigation, authentication, public
tour, notification text, browser notification icon, install manifest and error
pages. Searches remain Búsquedas, personal notification history becomes Timbres,
and delivery settings become Avisos. Keep prices/currencies/expenses explicit.
Use the supplied SVG geometry and licensed local font. Animate the authentication
logo without blocking the form; reduced-motion and no-JS show the final logo.

Preserve existing uncommitted operation-type, filter and scraping changes. Internal
Rails/database/deployment IDs, VAPID key derivation, notification tags, matching,
authorization and delivery semantics stay stable. No live scraper or notification
calls and no production deployment are included in this implementation request.

Validation: Rails suite compared with baseline, CSS mirror, browser desktop/mobile,
asset loading, animation completion/replay/Turbo restoration and reduced motion.
